# SPDX 3.0 Generator Container

Containerized SPDX 3.0 SBOM generator for Archifiltre using the official Python `spdx-tools` library with System Package Data Exchange 3.0 support.

## Overview

This container generates Software Bill of Materials (SBOM) in SPDX 3.0 format with enhanced security vulnerability integration. It follows the same containerized pattern as the Archifiltre security audit tooling for consistency and maintainability.

### Key Features

- **SPDX 3.0 Support**: Uses official `spdx-tools` Python library with experimental SPDX 3.0 capabilities
- **Security Integration**: Incorporates vulnerability data from security audit reports
- **Element-Based Architecture**: Leverages SPDX 3.0's enhanced element and relationship modeling
- **French Government Compliance**: Built for République française compliance requirements
- **Containerized Execution**: Isolated, reproducible environment using Podman

## Container Architecture

```
archifiltre/containers/spdx3-generator/
```

## Usage

### Basic Usage

Generate SPDX 3.0 SBOM with default settings:

```bash
bun run sbom:spdx3
```

### Available Scripts

| Script | Description |
|--------|-------------|
| `bun run sbom:spdx3` | Basic SPDX 3.0 generation |
| `bun run sbom:spdx3:compliance` | Compliance-focused generation with verbose output |
| `bun run sbom:spdx3:security` | Security-focused generation with verbose output |
| `bun run sbom:spdx3:dev` | Development mode with container rebuild |

### Manual Execution

```bash
# Run the TypeScript wrapper
bun run scripts/generate-spdx3-sbom.ts [options]

# Direct container execution (after building)
podman run --rm \
  -v "$(pwd):/workspace:ro" \
  -v "$(pwd)/dist/sbom:/output:rw" \
  -v "$(pwd)/security-reports:/security-reports:ro" \
  localhost/archifiltre-spdx3-generator:latest [options]
```

## Command Line Options

### TypeScript Wrapper Options

```
-h, --help              Show help message
-o, --output-dir DIR    Output directory (default: dist/sbom)
--exclude-dev-deps      Exclude development dependencies
-q, --quiet             Suppress output messages
-v, --verbose           Enable verbose output
--no-container-build    Skip container build/check
--force-rebuild         Force container rebuild
--no-security           Skip security data integration
```

### Python Generator Options

```
--include-dev-deps      Include development dependencies (default)
--exclude-dev-deps      Exclude development dependencies
--quiet                 Suppress output messages
```

## Integration with Security Audit

The SPDX 3.0 generator automatically integrates with security audit results:

1. **Security Reports Directory**: Reads from `security-reports/` directory
2. **Vulnerability Data**: Incorporates Trivy vulnerability findings
3. **Security Findings**: Includes Semgrep security analysis results
4. **Enhanced Metadata**: Adds security summary to package descriptions

### Security Data Integration

```yaml
# Example output with security integration
security_summary:
  total_vulnerabilities: 12
  total_findings: 3
  severity_breakdown:
    critical: 0
    high: 2
    medium: 8
    low: 2
```

## Container Management

### Automatic Container Building

The TypeScript wrapper automatically:
- Checks if container exists
- Builds container if needed
- Rebuilds if Containerfile is newer than existing image
- Handles build errors gracefully

### Manual Container Operations

```bash
# Build container manually
podman build -t localhost/archifiltre-spdx3-generator:latest \
  -f containers/spdx3-generator/Containerfile \
  containers/spdx3-generator/

# Check container exists
podman image exists localhost/archifiltre-spdx3-generator:latest

# Remove container
podman rmi localhost/archifiltre-spdx3-generator:latest
```

## SPDX 3.0 Features Used

- **Element-Based Architecture**: All components as elements with relationships
- **Enhanced Relationship Modeling**: Precise dependency and containment relationships
- **Software Purpose Classification**: Distinguishes applications from libraries
- **Security Metadata Integration**: Vulnerability information in element descriptions
- **Extended Agent Support**: Tool and organization identification

## Troubleshooting

### Common Issues

#### Container Build Fails
```bash
# Force rebuild with verbose output
bun run scripts/generate-spdx3-sbom.ts --force-rebuild --verbose
```

#### Podman Not Available
```bash
# Install Podman on Ubuntu/Debian
sudo apt-get update && sudo apt-get install podman

# Install Podman on macOS
brew install podman
```

#### Security Reports Not Found
The generator continues without security data if reports are missing. Run security audit first:
```bash
bun run security:audit
bun run sbom:spdx3
```

#### Permission Denied Errors
Ensure proper volume mounting permissions:
```bash
# Check output directory permissions
ls -la dist/sbom/
mkdir -p dist/sbom
```

### Debug Mode

Enable verbose output for troubleshooting:
```bash
bun run scripts/generate-spdx3-sbom.ts --verbose --force-rebuild
```
